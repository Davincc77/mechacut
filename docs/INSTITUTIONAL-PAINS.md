  review_rows, reviewer_name, decision_at, revocation} → sha canonique, ordre
  des dates vérifié, veto compté, champs manquants NOMMÉS ; oracle : trois
  roster tracés main (propre / champ vide / date inventée). Loi maison : la
  table des champs est fermée, jamais de déduction. Tier visé : free (route
  unique), batch payant au-delà de 32KB. Preuve : URL du post, crédit proposeur
  à la construction.
